# Client design-reference review

Reviewed the client’s reference email, the eight-slide September 17 proposal (especially Creative Direction), current website-content brief, and all five live reference homepages on 24 September 2026.

The agreed blend is “LUX-level polish + diagnostic positioning + Orewa-level approachability”. Later written instructions remove paediatrics and prioritise pregnancy, pelvic and abdominal scans.

| Reference | Observed design features | Application to Hobsonville |
| --- | --- | --- |
| [LUX Radiology](https://www.luxradiology.co.nz/) | Large rotating photographic hero, prominent booking navigation, illustrated service icons, contact/location icons. | A photographic slideshow, a proper medical icon system and a strong, persistent booking action. Preserve Hobsonville’s own teal/gold identity. |
| [Advance Ultrasound](https://www.advanceultrasound.co.nz/) | Large photographic slider, broad diagnostic positioning, separate patient/referrer pathways and appointment icons. | Show the breadth of the practice through image-led service navigation and clear preparation/pricing/referrer routes. |

| [UP Ultrasound](https://www.upultrasound.co.nz/) | Patient/referrer/service grouping and photographic exam listings; dense interface in places. | Retain useful grouping while using larger type, simpler navigation and comfortable controls, consistent with the client’s concern about older patients. |
| [Ultrasound Orewa](https://www.usorewa.co.nz/) | Spacious photographic opening, simple navigation, clear booking action and approachable local tone. | Keep the warmth and straightforward patient journey within a more polished Hobsonville presentation. |

## Client-specific requirements addressed

The client brief expressly asks for service images/icons, real clinic photography, a focused homepage, a useful map and readable controls. It also mentions liking the current site's animated image loading and service navigation. The redesign adds these visual and interactive elements while keeping preparation, prices and booking available as static HTML.

No competitor imagery, patient testimonials, affiliations or medical claims were copied. The existing local image inventory supplies the redesign. Clinical and availability approval items remain in the launch checklist.
